# PBS (PicleBall Scores App)

This application can be used to keep scores in a friendly pickle tournament.

It is not designed to be a commercial application.

The purpose to write this app is to learn HTML, CSS, JavaScript, and PWA deployment 

I'm basically following the PWA tutorial from: https://github.com/iamshaunjp/pwa-tutorial/tree/master

## Step1 created the 4 basic files
Using VS Code created: index.html, style.css, script.js & this README.md
