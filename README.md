# PBS (PickleBall Score App)

This application can be used to keep scores in a friendly pickle tournament.

It is not designed to be a commercial application.

The purpose to write this app is to learn HTML, CSS, JavaScript, and PWA deployment 

I'm basically following the PWA tutorial from: https://github.com/iamshaunjp/pwa-tutorial/tree/master

## Step1 created the 4 basic files
Using VS Code created: index.html, style.css, script.js & this README.md

Created the html boilerplate typing
```
doc <Tab>  
```
HTML reference from: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference

To preview the app using VSCode I installed the extension called "Live Server" which can be opened by right-clicking on top of _index.html_ 

To avoid creating all the styles from scratch I used the CSS templates downloaded from: https://materializecss.com/getting-started.html
CSS reference from: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference


## Step2 created the icons and the manifest 
I created the icon using Gemini AI. 
To resize the icon I used: https://www.adobe.com/express/feature/image/resize/png
And save three copies in three different sizes in a new directory called assets 

Then I created the file manifest.json 
Google docs regarding manifests: https://developers.google.com/web/fundamentals/web-app-manifest
and https://web.dev/articles/add-manifest
